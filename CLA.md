# Contributor License Agreement

Thank you for wanting to contribute. Please read this once; it is short, and it
explains a real trade the project is making rather than hiding it in legalese.

## Why this exists

The Project Brain is released under the **AGPL-3.0**. That license is the
project's protection: anyone may run and modify it, but offering it to others as
a network service means publishing your modified source.

Some organisations cannot accept those terms and would rather pay for a
**commercial license**. Selling one requires holding the rights to *all* of the
code — including yours. Without this agreement, a single merged contribution
would permanently foreclose that option, for the maintainer as much as for
anyone else, and the project would lose the only revenue model that could fund
its maintenance.

So the trade is stated plainly: **you keep your copyright**, and you grant the
maintainer the rights needed to keep both licenses on the table.

## How to sign

Add a `Signed-off-by` line to every commit — `git commit -s` writes it for you:

```
Signed-off-by: Your Name <your.email@example.com>
```

That line means: *"I have read CLA.md and I agree to it for this contribution."*
Use a real name and a reachable address. The first time you open a pull request,
say in the description that you have read and agree to `CLA.md`.

contribution, say so — it is worth knowing.
